Lorkan1 隐私说明

版本：0.4.0。生效日期：2026年11月1日。

单一用途

提供策略游戏的本机复盘与获许可环境中的AI实验菜单。本产品并非 FrontWars 或 Google 官方产品。

数据与处理

复盘文件只在你勾选同意并主动选择后于本机解析。完整原文件不保存；提取出的胜者复盘报告保存在扩展页面的本机浏览器存储中。你可以点击“清除本机复盘”删除报告。不会上传给开发者、广告平台或模型服务。

本地游戏菜单只向当前页面发送你选择的策略，并接收当前页面提供的游戏统计。不读取账户凭证、Cookie、聊天、联系方式或无关网站浏览内容。扩展不使用分析追踪或远程执行代码。

权限与外部链接

仅在清单列出的 frontwars.io、www.frontwars.io 和本地主机页面显示菜单；不申请全站访问权限、账户权限或历史记录权限。点击外部链接后，目标网站依其自己的规则处理访问。没有文件自动上传、自动抓取全站对局或公开上传功能。

保留、删除与有限使用

报告保留到你主动清除扩展数据或卸载。数据仅用于所描述的复盘功能，不出售，不用于广告、信用评估或无关画像，也不交由开发者人工读取。本产品对用户数据的使用遵守 Chrome Web Store User Data Policy 及 Limited Use 要求。
