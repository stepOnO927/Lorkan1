# 隐私与数据

版本：1.2.0。无内置广告或分析统计服务；无开发者数据收集端点。

扩展设置（保护开关、目标和当前房间）存储在 chrome.storage 中。各AI访客身份、原版席位及托管时限保存在对应标签页的 sessionStorage；扩展不导入本人账号令牌。游戏状态和指令由原版游戏服务提供与处理。后台心跳只维持明确开启的AI页。

用户可主动导出本地对局记录；记录可能含玩家名称、对局ID与操作，请自行选择是否分享。源码发布不包含本人的对局导出、截图、账号昵称或访问凭据。

关闭AI页可结束该页会话；卸载扩展或在浏览器中清除扩展存储可移除扩展设置。游戏网站自己的存储与隐私政策独立适用。
