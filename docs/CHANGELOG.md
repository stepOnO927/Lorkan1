# 变更记录

## 1.6.0

- 成功登陆的滩头一次有限接应；受限的后期海运收益排序。
- 旧四败局最终4/4胜，新30种子首轮29/30；同代码回归30/30。完整败局和被弃试验保留。
- 放宽来袭门槛、无条件海运收益等退步试验未合入。
- 20个测试文件与语法通过；并非公网验收或所有种子全胜证明。

## 1.5.1

- 实际双线来袭预算、已有战线有限增援、实际可用兵力扩张、谨慎限时续约。
- 30种子首次23胜7负；最终相同源代码26胜4负，未达到全胜，败局完整保留。
- E局复验获胜；中等出生间距、前线防御塔和海运优先实验弃用。
- 18个检查文件通过，原版增援实际扣兵验证通过。

## 1.4.5

- 人口上限缺值时补读原版playerProfile，仍缺值则暂停军事决策。
- 撕约按完整留存兵力估算反击，而非30%/35%比例。
- 最终版六种子本地普通资源Medium限时赛5胜1负；停止领先者外交实验已回滚。
- 更正旧批次人口上限缺失问题，不将旧批次用于新版胜率估计。

## 1.4.3 候选版

- 增加有限弱人机突袭，限定在前期原本等待的阶段，保留正常进攻优先级及全部防守约束。
- 12局原版本地迭代记录：基线、两组失败实验、最终候选；最终候选4局1胜3负，未证明更强。

## 1.4.1

- 城市附近密集搜索防空合法点，轮换候选避免查询饥饿。

## 1.4.0

- 分散城市选址，按原版合法落点重验间距。
- 区域工厂首次建设与原版铁路保持兼容。
- 多区域、多层防空按实际缺口补建，在建与已完成分开计数。
- 核威胁下先补现有城市防空，再扩城；拒绝缺乏防空空间的新城市位置。
- 本地原版双原子弹样本中两次拦截、核心城市存活；不作为普遍拦截保证。

## 1.3.0

- 后期争地不再受本国领土大小及人口容量比例阻塞。
- 留守按最强接壤敌人、两个敌军合击、来袭部队和撕约惩罚计算。
- 后期陆战先找可获地的安全目标；空地使用有限兵力持续扩张。
- 真人前期避战、己方保护及谨慎结盟继续有效。
- 菜单显示争地判断、最强敌军与留守预算。
- 已测试预算条件及原版引擎实际执行；尚未证明稳定胜率提升。
