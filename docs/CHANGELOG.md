# 变更记录

## 1.4.0

- 分散城市选址，按原版合法落点重验间距。
- 区域工厂首次建设与原版铁路保持兼容。
- 多区域、多层防空按实际缺口补建，在建与已完成分开计数。
- 核威胁下先补现有城市防空，再扩城；拒绝缺乏防空空间的新城市位置。
- 本地原版双原子弹样本中两次拦截、核心城市存活；不作为普遍拦截保证。

## 1.3.0

- 后期争地不再受本国领土大小及人口容量比例阻塞。
- 留守按最强接壤敌人、两个敌军合击、来袭部队和撕约惩罚计算。
- 后期陆战先找可获地的安全目标；空地使用有限兵力持续扩张。
- 真人前期避战、己方保护及谨慎结盟继续有效。
- 菜单显示争地判断、最强敌军与留守预算。
- 已测试预算条件及原版引擎实际执行；尚未证明稳定胜率提升。
