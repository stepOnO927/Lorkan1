# Lorkan1

OpenFront 四策略本地引擎对战回放。直接打开 index.html，无需启动服务器或联网。现代 Chrome 支持内置 gzip 解压。默认16倍速，从追加赛第25局开始；可选择全部72局。

GitHub Pages：仓库 Settings → Pages → Deploy from a branch → main / (root)。

## v0.3.1 完整游戏实时托管

本地运行完整 OpenFront 网页客户端（不是 FrontWars 官方服务，版本和界面可能不同）。游戏地图、军队、建筑、经济、外交和战斗使用上游游戏引擎与渲染。菜单通过正常单人指令通道控制正在看的对局；不再启动另一个抽象回放代替当前游戏。

本机地址：http://127.0.0.1:9010/

进入单人模式，选择地图和难度，右侧选策略并点击“开启托管”。AI 自动选出生点、扩张、攻击、建设城市/港口/要塞，按策略处理结盟与渡海。点击“停止托管 / 手动接管”停止新指令；已经发出的进攻仍由游戏继续结算。策略为固定规则加自动参数搜索，已加入铁路连通选址、军舰巡航、防空覆盖与核武目标评估；尚未验证能稳定击败最高难度。

### Chrome 安装

1. 下载本仓库，解压。
2. 在 Chrome 打开 chrome://extensions，开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择 extension 文件夹。
4. 打开本地游戏；菜单自动出现。FrontWars 官方页面只显示回放和本地游戏入口。

扩展无额外 API 权限，只在清单列出的游戏和本地主机页面注入菜单。为方便未安装扩展时验证，本地修改版也内置同一菜单，两者自动去重。

### 复现完整本地游戏

使用上面固定提交的 OpenFront 仓库，在根目录执行 git apply /path/to/local-game.patch，按上游文档安装依赖，然后执行 node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 9010 --strictPort。Start-LocalGame.ps1 为本机现有目录准备启动入口；其他目录可设置 OPENFRONT_DIR。修改源码通过 local-game.patch 提供，并遵循上游 AGPL-3.0；见 LICENSE-OpenFront。上游素材保留原许可与版权标识。

### 验证

TypeScript 检查通过；四种策略各在真实引擎执行1000刻，均自动出生、扩张并建立建筑；非单人模式返回无操作。完整网页实际验证了自动出生、攻击、建筑、切换策略和停止托管。扩展安装与 Chrome 页面验证另行记录。

## v0.3.1 本轮升级与证据

旧版城市优先的固定顺序让工厂很难获得预算；选址不评估铁路；没有军舰、防空和核弹决策。新版采用建筑配额、铁路实际可达路径检查、基础设施防空覆盖、军舰建造与敌船拦截、核弹友军损伤/重复目标/拦截路径评估，符合条件时使用 MIRV。受袭时撤回外派兵，降低扩张支出。

新单人局强制国家难度为 Impossible（地狱）；基础部落默认0，使用完整国家AI。部落行为没有难度档位，关闭可避免拿基础部落充当最高难度对手。无无限资源或即时建造。

功能验证：控制后期场景（双方成熟领土、等额200M起始资金，敌方静止，不计胜场）实际出现氢弹、5艘军舰、26个连通站点和184万铁路收入。另两场地狱国家AI、高起始资金对战在1800刻均存活，分别获得272万/175.5万铁路收入，以及约77.7万/22.5万海运收入。常规开局四局比较：旧版均淘汰，新版一局存活到3600刻；没有已验证胜场。样本很小，不是胜率结论。

自动迭代是参数搜索，不是神经网络训练。每代3组参数先在2局训练种子比较，再让最优候选与当前版本在另外2个留出种子对照；综合存活、最大领土、游戏时长、铁路收入评分，且不得减少胜场，只有留出成绩更好才接受。第一代留出评分0.5811→1.6265，留出存活0/2→1/2，无胜场。采用较保守扩张和更高进攻门槛。

在引擎目录运行 lorkan-evolve.cjs，可通过 GENERATIONS 指定后续轮数。训练结果写到引擎两级上方 outputs；已接受的参数从 /lorkan/profile 在新对局初始化时载入，当前对局不被训练参数更新中断。/lorkan/training 查看本机训练状态。已在本机启动后续10代；关闭电脑或终止训练进程后停止，不在GitHub远程持续运行。新版本需要新开对局；旧存档不会自动变成最高难度。

追加功能验证：独立控制场景分别只允许原子弹或MIRV，实际观察到原子弹、MIRV及其分弹头；这类固定敌方场景仍不计入胜场。

## 0.4.0 beta：目标域名与商店准备

目标已纠正为 https://frontwars.io/ 和 www.frontwars.io。扩展清单、研究室和页面诊断对应此站；不再匹配错误的frontwars.org。

这是研究版：官方当前运行时与本地OpenFront桥接不兼容，官方自动托管和原生回放导入尚未通过验证；不能把菜单出现当成已能代打。用户已在本次任务确认全部范围授权。仍需运营方提供当前版本状态/指令接口或对应源码，才能完成可靠托管。官方about.txt声明当前版本闭源，不能将归档仓库当成线上AI源码。

胜者采集不再在我们的AI死亡时停局。lorkan-winners.ts继续到引擎判胜或15000刻；只对正式胜者生成画像，未决局排除。每100刻记录各方状态，观察建筑首次出现、终局持有、铁路/海运收入和在途进攻比例。首次出现也可能来自缴获，不等于建造指令。winner-proposal.json仅是待测试假设；后续迭代在独立种子上验证才接受。设置LEARN_WINNERS=1运行lorkan-evolve.cjs可在每代先采集完整局；lorkan-followup.cjs在当前批次结束后串行进入这一流程，避免两个训练进程同时写参数。

研究室：lab.html。附带样本是真实本地完整游戏的记录，不是官方FrontWars对局。商店安装包、介绍、隐私说明、128px图标及1280×800真实界面截图已准备，见store目录。尚未注册开发者账号、未上传、未提交审核、未上架。具体待办见store/RELEASE-READINESS.md。
