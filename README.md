# Lorkan1

[![License: AGPL-3.0](https://img.shields.io/badge/License-AGPL--3.0-blue.svg)](LICENSE)

用于获许可 FrontWars 私人房间的规则型 AI 浏览器扩展，以及 OpenFront 本地对战回放实验。当前扩展版本 **1.2.0**；实验项目，不能保证胜率，尚未完成公网全流程验收。

## 安装最新版扩展

1. 在本仓库选择 **Code → Download ZIP** 并解压。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，开启开发者模式。
3. 选择“加载解压缩的扩展”，选中仓库中的 **extension** 文件夹。
4. 打开你获许可使用AI的 FrontWars 私人房间；更新旧版后刷新本人和AI页面。
5. 展开右侧小方块，逐个添加AI，然后点“一键勾选并启动全部AI”。本人保持手动。

从0个开始、每次添加1个、上限25个。实际入房数量受原版房间容量和服务器接收限制；小地图可能出现友方包围、无扩张出口。

## 功能

- 25个角色分别使用独立访客存储和原版席位，不复制本人的登录凭据。
- 一键启停、折叠菜单、后台心跳和有界超时恢复；主动停止和服务器拒绝仍有效。
- 扩张、经济、防空防守、后期突破四种规则配置轮换分配。
- AI互保和护主分开设置；护主绑定当前本人的对局席位，公开版不包含固定玩家昵称。
- **复仇**：开局前刷新名单，选择其他玩家的本局ID，启用后在其公开落点附近选择合法出生点。不能强制复活已淘汰AI。
- **追杀**：开局后从列表或地图选择玩家/系统人机，按兵力和路径条件共同进攻。
- 正在交战、己方围攻、明显能攻克及接近收尾的敌人不临阵结盟；指定目标不求和，已有盟约仍评估原版撕约惩罚。

## 适配与实测范围

当前接入针对缓存验证过的 FrontWars 客户端 **42.5** 及固定模块入口。网站更新可能让桥接失效；菜单会报告连接、名单或版本问题。只在原版状态明确为 `Private` 时发送游戏操作。这里的代码和许可证不代表网站运营方对任何用户的使用授权。

本地缓存原版引擎的25角色短局中：25个均选点、24个发出攻击，1个在小地图被友方围住。不是25个公网客户端已验证，也不是胜率证明。复仇样本中8个AI在选定的受控玩家周边出生并实际发出目标攻击指令。

## 开发与测试

无需安装依赖；使用 Node.js 24 或更高版本，在仓库根目录执行：

```sh
node scripts/test.mjs
npm run check
```

测试直接加载发布源码，覆盖结盟的最终发令拦截、25角色批量启停、目标入口与回执、复仇等待、优势进攻及超时恢复。浏览器、网络与游戏状态使用受控替身，因此不替代公网验收。测试不包含网站客户端、WASM或私有账号数据。

## 本地回放与历史版本

[回放页面](https://stepono927.github.io/Lorkan1/) 保留原有本地引擎比赛。历史结果使用旧版策略和固定实验条件，不能作为1.2.0对真人的胜率。旧版扩展归档在 [legacy/extension-0.3.1](legacy/extension-0.3.1)，原项目说明见 [docs/legacy-README.md](docs/legacy-README.md)。

## 隐私

扩展不内置分析服务，不上传账号凭据。策略设置保存在浏览器扩展存储中，访客席位和托管状态保存在对应页面会话中；游戏操作发往原游戏服务。导出记录仅在用户主动点击时下载到本机。更多说明见 [docs/PRIVACY.md](docs/PRIVACY.md)。
